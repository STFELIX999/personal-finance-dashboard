# Personal Finance Dashboard

A backend application built using Spring Boot to manage personal finances.

## Technologies Used:

* Java 21
* Spring Boot
* Spring Data JPA
* Hibernate
* MySQL
* Maven
* Git
* GitHub
* Postman

## Features:

### User Management

* User Registration
* User Login
* Duplicate Email Validation

### Category Management

* Create Category
* View Categories

### Income Management

* Add Income
* View Incomes
* Filter Income by Source
* Total Income Analytics

### Expense Management

* Add Expense
* Update Expense
* Delete Expense
* View Expenses
* Filter by Category
* Filter by Date Range
* Pagination
* Sorting
* Expense Analytics

### Dashboard

* Total Income
* Total Expense
* Remaining Balance

## API Features:

* DTO Pattern
* Validation
* Global Exception Handling
* JPQL Queries
* Pagination
* Sorting
* Filtering

## Future Enhancements:
